# お絵かきアプリ

HTML / CSS / JavaScript だけで動く、シンプルなお絵かきアプリです。ビルドやインストールは不要です。

## 使い方

`index.html` をブラウザで開くだけで動きます。ローカルサーバーで確認したい場合は次のコマンドを実行し、`http://localhost:8000` を開いてください。

```bash
python3 -m http.server 8000
```

## 機能

- ペンで自由に描画（マウス・タッチペン・指に対応）
- 消しゴム
- 選択中のツールに合わせてマウスカーソルの形が変化
- カラーピッカーと 6 色のパレット
- 線の太さ調整（1〜60px）
- 元に戻す / やり直す（最大 30 手）
- 全消去
- PNG 画像として保存

## ショートカット

| キー | 動作 |
| --- | --- |
| `Ctrl` / `⌘` + `Z` | 元に戻す |
| `Ctrl` / `⌘` + `Shift` + `Z` | やり直す |

## ファイル構成

- `index.html` — 画面の構造
- `style.css` — 見た目
- `script.js` — 描画処理

## 注意点

ウィンドウサイズを変えるとキャンバスを作り直すため、絵は残りますが操作履歴（元に戻す / やり直す）はリセットされます。
